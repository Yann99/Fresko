# Fresko — Version 4.1

Correctif PWA pour le dépôt GitHub Pages `Fresko`.

## Mise à jour du dépôt
1. Décompresser cette archive.
2. Dans GitHub, ouvrir le dépôt `Fresko` → **Add file** → **Upload files**.
3. Envoyer tous les fichiers contenus dans ce dossier à la racine du dépôt.
4. Accepter le remplacement des fichiers existants, puis **Commit changes**.
5. Attendre quelques minutes que GitHub Pages republie le site.

Les fichiers d'icônes sont volontairement à la racine du dépôt. Les références dans `index.html` et `manifest.webmanifest` correspondent à cet emplacement.

## Installer / mettre à jour sur Android
1. Ouvrir l'adresse GitHub Pages dans Chrome.
2. Recharger la page après la publication.
3. Si l'installation échoue encore, ouvrir Chrome → Paramètres → Paramètres des sites → Toutes les données des sites, rechercher le site Fresko et effacer ses données, puis rouvrir l'adresse.
4. Dans Chrome, menu ⋮ → **Installer l'application** si l'option est proposée.

## Données
Les stocks et listes de courses restent enregistrés localement sur chaque appareil/navigateur. Il n'y a pas de synchronisation entre appareils. Les fonctions IA ne sont pas connectées dans cette version.
